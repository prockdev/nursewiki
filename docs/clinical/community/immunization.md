# Immunization

Prevention of infectious disease through vaccination.

## Common Vaccines

| Vaccine | Protects Against |
|---|---|
| BCG | Tuberculosis |
| OPV/IPV | Polio |
| Pentavalent | DTP, HepB, Hib |
| Measles-Rubella | Measles, Rubella |
| Yellow Fever | Yellow Fever |

## Nursing Role

- Assess contraindications
- Administer safely
- Document
- Educate caregivers
- Monitor for adverse events
